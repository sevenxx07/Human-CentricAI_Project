Reinforcement Learning with Human Feedback

Project Description

In this project, we implement Reinforcement Learning with Human Feedback (RLHF) using a mouse navigation environment. The mouse learns to navigate a 5x5 grid to collect cheese while avoiding traps and learning to avoid organic cheese based on human preferences. The project demonstrates policy training, reward modeling from preferences, and policy retraining with learned rewards.

Training Tasks

Task 2: Simulated Preferences

Generate trajectory preferences automatically using a simulated preference function. This trains a reward model to predict human preferences without actual human input.

What it does:
  • Samples trajectories from current policy
  • Generates pairwise preferences automatically
  • Trains reward network using Bradley-Terry model

Task 3: Policy Retraining

○ Ready

Retrain the policy using the learned reward model with KL regularization. The mouse learns to optimize the learned human preferences while staying close to the original policy.

What it does:
  • Loads trained reward model from Task 2a
  • Retrains policy with learned rewards + KL penalty
  • Evaluates performance before and after training
