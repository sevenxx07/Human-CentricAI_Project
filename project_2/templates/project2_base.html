Active Learning for Text Classification

Project Description

In this project, a binary classifier is trained for sentiment analysis on the IMDB 50k movie reviews dataset with the purpose of being able to classify reviews as either positive or negative. The IMDB dataset has been cleaned and pre-processed and finally encoded from text into a real vector represented using a TF-IDF representation. If you wish to load a pre-trained model, please do so by clicking the button below. For training the model from scratch, please proceed to task 1.
