Active Learning for Text Classification

Project Description

In this project, a binary classifier is trained for sentiment analysis on the IMDB 50 k movie reviews dataset with the purpose of being able to clasify reviews as either positve or negtaive. The IMDB dataset has been cleaned and pre-processed and finally encoded from text into a real vector represented using a TF-IDF representation.
