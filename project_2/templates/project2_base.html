Active Learning for Text Classification

Project Description

In this project, a binary classifier is trained for sentiment analysis on the IMDB 50 k movie reviews dataset with the purpose of being able to clasify reviews as either positve or negtaive. The IMDB dataset has been cleaned and pre-processed and finally encoded from text into a real vector represented using a TF-IDF representation.

Logistic Regression

The classifier used for this sentiment analysis is Logistic Regression. This is a statistical method used for binary classification, predicting binary outcomes (here: positive/negtative). It is a type of supervised machine learning algorithm that uses the sigmoid function to model the probability of a positive outcome based on the input data.
